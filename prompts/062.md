### ۰.۳ باگ A-01 — چرا کلید ناپدید می‌شود

`AIGateway._loadConfig` کلید را این‌طور می‌خواند:

```dart
var apiKey = await SecureKeyStore.getKey(apiKeyKey) ?? settingsMap[apiKeyKey];
```

و `SecureKeyStore.getKey` وقتی مقدار را در حافظهٔ امن پیدا نکند، از `app_settings` می‌خواند و بعد:

```dart
await setKey(keyName, legacyVal);
await db.delete('app_settings', where: 'key = ?', whereArgs: [keyName]);
return legacyVal;
```

یعنی **ردیف را از `app_settings` پاک می‌کند**. اما شیت تنظیمات فقط `settingsMap['ai_api_key']` را می‌خواند و هرگز `SecureKeyStore.getKey` را صدا نمی‌زند.

<aside>
💥

نتیجهٔ عملی: کاربر کلید را ذخیره می‌کند، دستیار کار می‌کند، بعد تنظیمات را باز می‌کند و **فیلد کلید خالی است**. فکر می‌کند تنظیماتش پاک شده، دوباره وارد می‌کند، و این چرخه تکرار می‌شود. این تنها باگی است که به‌تنهایی ارزش این پرامپت را توجیه می‌کند.

</aside>

### ۰.۴ باگ A-02 — دام آدرس

`_postChat` این کار را می‌کند:

```dart
final response = await client.post(Uri.parse(config.baseUrl), headers: headers, body: ...);
```

هیچ مسیری به آدرس اضافه نمی‌شود. پس مقدار ذخیره‌شده باید **آدرس کامل** باشد، مثل `https://open.bigmodel.cn/api/paas/v4/chat/completions`. ولی برچسب فیلد می‌گوید «آدرس سرویس‌دهنده (Base URL)».

هر کسی که طبق عرف جهانی `https://api.openai.com/v1` را بچسباند، ۴۰۴ می‌گیرد بدون هیچ توضیحی. این پرتکرارترین شکست پیکربندی است.

### ۰.۵ باگ A-03 — صفحهٔ تنظیمات دروغ می‌گوید

دو بازنویسی مستقل روی نام مدل انجام می‌شود:

**یک) موقع بارگذاری** در `_loadConfig`: اگر مدل `glm-4.7-flash` بود به `glm-5.2` و اگر `@cf/zai-org/glm-5.2` بود به `@cf/zai-org/glm-4.7-flash` تغییر می‌کند و **در دیتابیس هم نوشته می‌شود**.

**دو) موقع ارسال** در `_effectiveModel`:

```dart
if (config.baseUrl.contains('cloudflare.com')) {
  if (preferLightCloudflareModel) return '@cf/meta/llama-3.2-3b-instruct';
  if (!config.model.startsWith('@cf/')) return defaultModel;
} else if (config.baseUrl.contains('bigmodel.cn')) {
  if (config.model.startsWith('@cf/')) return defaultFeaturesModel;
}
```

پس کاربر مدل A را می‌نویسد، دفعهٔ بعد مدل B را می‌بیند، و در واقع مدل C فرستاده می‌شود. **راه‌حل درست پنهان‌کردن این رفتار نیست، شفاف‌کردن آن است.** جزئیات در T-A6 و T-B5.

## ۳. تصمیم‌های قطعی طراحی (بحث نکن، اجرا کن)

<aside>
🧭

بینش مرکزی: کاربر هیچ‌وقت نمی‌پرسد «base URL من چیست». همیشه می‌پرسد **«چرا دستیار کار نمی‌کند؟»**. پس این صفحه یک فرم نیست، یک **اتاق کنترل اتصال** است. فیلدهای اعتبارنامه جزئیات پیاده‌سازی‌اند که زیر جواب آن سؤال قرار می‌گیرند.

</aside>

1. **صفحهٔ کامل، نه شیت.** دقیقاً به همان دلیلی که در پرامپت ۰۴۷ گام ۳.۱ شیت تم به `theme_settings_screen.dart` تبدیل شد: فضا کم است. شیت فعلی حذف کامل می‌شود.
2. **دو حالت اتصال:** «سرور ریتمو» (از طریق `AIProxyService`، بدون هیچ کلیدی روی دستگاه) و «کلید شخصی». پیش‌فرض برای کاربر جدید «سرور ریتمو» است. **۹۰٪ کاربرها نباید هرگز کلمهٔ API را ببینند.**
3. **آدرس نرمال‌سازی می‌شود، نه اینکه برچسبش عوض شود.** کاربر هرچه بچسباند، `AiEndpointNormalizer` آن را به endpoint معتبر تبدیل می‌کند و آدرس نهایی را زیر فیلد نشان می‌دهد.
4. **کلید همیشه از `SecureKeyStore` خوانده می‌شود، هرگز از `app_settings`.** این A-01 را می‌بندد.
5. **بازنویسی مدل شفاف می‌شود.** به‌جای عوض‌کردن بی‌سروصدا، زیر فیلد مدل یک هشدار کهربایی نشان بده که چه چیزی واقعاً فرستاده می‌شود.
6. **آزمایش اتصال زنجیره را دور می‌زند.** اگر آزمایش از زنجیره رد شود، ممکن است با کلید دیگری موفق شود و به کاربر دروغ بگوید.
7. **ذخیره هرگز به آزمایش موفق مشروط نیست.** کاربر همیشه می‌تواند ذخیره کند؛ کارت وضعیت کهربایی می‌شود.
8. **پیش‌فرض `ai_timeout` از ۲۰۰ ثانیه به ۶۰ ثانیه می‌آید** و قابل تنظیم می‌شود.

### T-A2 — نرمال‌ساز آدرس

**فایل جدید:** `lib/core/ai/ai_endpoint_normalizer.dart`

```dart
class AiEndpointNormalizer {
  AiEndpointNormalizer._();

  /// ورودی خام کاربر را به endpoint کامل chat/completions تبدیل می‌کند.
  static String normalize(String raw, {bool allowHttp = false});

  /// اگر آدرس غیرقابل‌استفاده است، پیام خطای فارسی برمی‌گرداند؛ وگرنه null.
  static String? validate(String raw, {bool allowHttp = false});
}
```

قواعد دقیق `normalize` — به همین ترتیب اعمال کن:

1. `trim()` و حذف اسلش انتهایی تکراری.
2. اگر هیچ scheme نداشت، `https://` اضافه کن.
3. اگر مسیر با `/chat/completions` تمام می‌شود → دست نزن.
4. اگر مسیر با `/v1` یا `/v1/` تمام می‌شود → `/chat/completions` اضافه کن.
5. اگر مسیر خالی است (فقط host) → `/v1/chat/completions` اضافه کن.
6. در بقیهٔ حالت‌ها → `/chat/completions` اضافه کن.

قواعد `validate`:

- خالی → `'آدرس سرویس‌دهنده را وارد کنید'`
- `Uri.tryParse` ناموفق یا host خالی → `'آدرس معتبر نیست'`
- scheme برابر `http` و `allowHttp == false` و host جزو `localhost` / `127.0.0.1` / `10.0.2.2` نیست → `'فقط آدرس امن (https) پذیرفته می‌شود'`
- هنوز حاوی `{ACCOUNT_ID}` یا `YOUR_ACCOUNT_ID` → `'شناسهٔ حساب Cloudflare را جایگزین کنید'`

### T-A8 — مهاجرت

**فایل جدید:** `lib/core/database/migration/migrations/migration_vNN_ai_connection.dart` — `NN` را از پیش‌پرواز بگیر.

```dart
class MigrationVNNAiConnection implements Migration {
  @override
  int get version => NN;

  @override
  Future<void> up(Database db) async {
    final now = DateTime.now().millisecondsSinceEpoch;

    Future<void> put(String key, String value) => db.insert(
          'app_settings',
          {'key': key, 'value': value, 'updatedAt': now},
          conflictAlgorithm: ConflictAlgorithm.replace,
        );

    // ۱. نگاشت یک‌بارهٔ مدل‌های منسوخ (منتقل‌شده از _loadConfig)
    await db.rawUpdate(
      "UPDATE app_settings SET value = 'glm-5.2', updatedAt = ? "
      "WHERE key IN ('ai_model','ai_features_model') AND value = 'glm-4.7-flash'",
      [now],
    );
    await db.rawUpdate(
      "UPDATE app_settings SET value = '@cf/zai-org/glm-4.7-flash', updatedAt = ? "
      "WHERE key IN ('ai_model','ai_features_model') AND value = '@cf/zai-org/glm-5.2'",
      [now],
    );

    // ۲. تایم‌اوت پیش‌فرض عاقلانه
    final t = await db.query('app_settings', where: 'key = ?', whereArgs: ['ai_timeout']);
    if (t.isEmpty) await put('ai_timeout', '60000');

    // ۳. حالت اتصال: کاربر فعلی که کلید دارد نباید رفتارش عوض شود
    final existing = await db.query(
      'app_settings',
      where: "key IN ('ai_api_key','ai_features_api_key','ai_base_url') AND value != ''",
    );
    final legacyKey = await SecureKeyStore.getKey('ai_api_key');
    final hasAnything = existing.isNotEmpty || (legacyKey != null && legacyKey.isNotEmpty);
    await put('ai_mode', hasAnything ? 'personal_key' : 'ritmo_server');

    // ۴. حدس پیش‌تنظیم از روی آدرس فعلی
    final urlRow = await db.query('app_settings', where: 'key = ?', whereArgs: ['ai_base_url']);
    final url = urlRow.isNotEmpty ? (urlRow.first['value'] as String? ?? '') : '';
    final preset = url.contains('bigmodel.cn')
        ? 'zhipu'
        : url.contains('openrouter.ai')
            ? 'openrouter'
            : url.contains('cloudflare.com')
                ? 'cloudflare'
                : url.contains('groq.com')
                    ? 'groq'
                    : 'custom';
    await put('ai_provider_preset', preset);
  }
}
```

**ویرایش‌های الزامی:** `_dbVersion` را در `database_helper.dart` به `NN` ببر و `MigrationVNNAiConnection()` را به انتهای `_migrations` در `migration_runner.dart` اضافه کن. اگر این دو را نکنی مهاجرت هرگز اجرا نمی‌شود.

- در حالت پیش‌فرض مقدار را ماسک نشان بده: چهار کاراکتر آخر واقعی، بقیه `•` — مثلاً `••••••••••4f2a`
- آیکن چشم برای نمایش موقت مقدار کامل
- آیکن `Icons.content_paste_rounded` که با `Clipboard.getData(Clipboard.kTextPlain)` مقدار را می‌چسباند و `trim()` می‌کند
- اگر مقداری ذخیره شده، یک دکمهٔ متنی «حذف کلید» با `colors.error` که `AiConnectionRepository.deleteKey` را صدا می‌زند و اول `RitmoDialog` تأیید می‌گیرد
- مقدار اولیه **حتماً** از `AiConnectionRepository.load()` بیاید که خودش از `SecureKeyStore` می‌خواند

**مدل** — یک `DropdownButtonFormField<String>` با گزینه‌های `preset.models` به‌علاوهٔ گزینهٔ «مدل دلخواه» که یک `RitmoTextField` آزاد باز می‌کند.

زیر فیلد مدل، اگر `AIGateway.instance.previewEffectiveModel(baseUrl: …, model: …)` با مقدار تایپ‌شده فرق داشت، یک `Row` با `Icons.info_outline_rounded` و رنگ `colors.warning` و `fontSize: 11`:

> این مدل با این سرویس‌دهنده سازگار نیست. ریتمو به‌جای آن «`{resolved}`» را می‌فرستد.
> 

این A-03 را از یک دروغ به یک اطلاع‌رسانی تبدیل می‌کند.

### T-B6 — کلید پشتیبان

یک `ExpansionTile` بدون `Divider` پیش‌فرض، عنوان «کلید پشتیبان» و زیرعنوان «اختیاری». باز که شود:

> وقتی سهمیهٔ کلید اول تمام شود یا سرویس‌دهنده پاسخ ندهد، ریتمو خودکار سراغ این کلید می‌رود. لازم نیست از همان سرویس‌دهنده باشد.
> 

دو فیلد: آدرس پشتیبان (`ai_base_url_2`) و کلید پشتیبان (`ai_api_key_2`، با همان `AiSecretField`). یک دکمهٔ آزمایش جداگانه برای همین زوج.

این بخش A-04 را از قابلیت نامرئی به قابلیت واقعی تبدیل می‌کند.

### T-B7 — پیشرفته

یک `ExpansionTile` دیگر با عنوان «پیشرفته»:

1. **مهلت پاسخ** — `RitmoSegmentedControl<int>` با گزینه‌های `{15000: '۱۵ ثانیه', 30000: '۳۰ ثانیه', 60000: '۶۰ ثانیه', 120000: '۲ دقیقه'}` روی `ai_timeout`.
2. **پیکربندی جدا برای قابلیت‌ها** — یک `SwitchListTile` با عنوان «سرویس‌دهندهٔ جداگانه برای تحلیل‌ها». خاموش که باشد، `ai_features_*` از `ai_*` تبعیت می‌کند. روشن که باشد، سه فیلد `ai_features_*` ظاهر می‌شوند با این توضیح:

> «دستیار» چت زنده است و به سرعت نیاز دارد. «تحلیل‌ها» کارهای سنگین‌تر پس‌زمینه مثل خلاصهٔ هفتگی است. می‌توانید برای هرکدام سرویس‌دهندهٔ متفاوتی بگذارید.
> 

این A-12 را می‌بندد.

### T-C1 — پنل «زنجیرهٔ اتصال»

این A-06 را از یک جعبهٔ سیاه چنددقیقه‌ای به یک رفتار قابل‌فهم تبدیل می‌کند.

## ۱۰. قواعد سخت

1. **کلید API فقط در `SecureKeyStore`.** بعد از این کار `rg -n "app_settings.*ai_api_key" lib/` نباید هیچ نوشتنی نشان بدهد.
2. **هیچ کلیدی در لاگ، حتی طولش.**
3. **هیچ رنگ هاردکد** جز رنگ برند سرویس‌دهنده‌ها که در `kAiProviderPresets` تعریف می‌شود.
4. **هیچ عدد لاتین در UI.** همه `RitmoNumber.fa`.
5. **هر `TextEditingController` فیلد کلاس است و `dispose` می‌شود.**
6. **هیچ `future:` درون‌خطی در `FutureBuilder`.**
7. **صفحه هرگز مستقیم `DatabaseHelper` را صدا نمی‌زند** — فقط `AiConnectionRepository`.
8. **آزمایش اتصال هرگز از `_configChain` رد نمی‌شود.**
9. **ذخیره هرگز به آزمایش موفق مشروط نیست.**
10. **هیچ ستون یا کلید جدیدی خارج از مهاجرت این پرامپت اضافه نشود.**
11. **رفتار فعلی کاربرانی که کلید دارند نباید عوض شود.** مهاجرت باید `personal_key` بگذارد.
12. حداقل هدف لمسی ۴۸ پیکسل روی همهٔ آیکن‌های تعاملی.
