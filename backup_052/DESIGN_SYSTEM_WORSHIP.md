## 🕌 فلسفه: چرا این صفحه خاص است؟

برخلاف بقیه‌ی سیستم‌ها که «مدیریت زندگی دنیوی» هستند، عبادت **تنها** سیستمی است که مستقیماً با بُعد معنوی انسان سروکار دارد. اصول طراحی آن:

| اصل | پیامد طراحی |
|------|-------------|
| **تشویق، نه تحقیر** | هرگز برای قضاشدن نماز/روزه کاربر را سرزنش نکنیم. زبان: «تا حالا ۱۲ تا قضا دادی، خب حالا بیا جبران کن» ❌ ← «۱۲ نماز در انتظار توست برای جبران — هر روز یکی با هم بریم جلو» ✅ |
| **وقت‌شناسی = محور** | کل صفحه حول «الان وقت چیه؟» و «نماز بعدی تا چند دقیقه دیگه‌ست؟» می‌چرخد. |
| **ارتباط با بدن** | عبادت از وضعیت جسمانی زن (قاعدگی، بارداری) تأثیر می‌پذیرد — این اتصال باید محترمانه و خودکار باشد، نه دستی. |
| **اختیاری بودن** | هیچ یادآوری‌ای بدون تیک کاربر فعال نمی‌شود. کاربر **انتخاب** می‌کند کدام نماز/ذکر را یادآوری کند. |
| **زبان و لحن** | فارسی روان با اصطلاحات اسلامی (فجر، ظهر، عصر، مغرب، عشا، نافله، تهجد، تسبیحات، قضا، کفاره، اعتکاف...). |

## ☀️ کارت Hero — اوقات شرعی امروز

> داده: `prayer_times_cache` (join با `iran_cities`) · `prayer_time_provider.dart` · `app_settings`

### ساختار بصری
یک کارت **پهن و شیشه‌ای** در بالای صفحه، با گرادیان آسمان (کهربایی ملایم سحرگاه تا آبی نیلی شب):

**ردیف بالا: ۵ وقت اصلی در یک نوار افقی**
- فجر · طلوع · ظهر · غروب · مغرب · عشا
- هر کدام: نام (فارسی) + ساعت (ارقام فارسی) + آیکون (☀️🌅🌙)
- رنگ متن بر اساس وقت: فجر (کهربایی)، ظهر (طلایی)، مغرب (نارنجی)، عشا (نیلی)

**ردیف وسط: شمارش معکوس زنده تا نماز بعدی**
- «⏳ تا اذان [ظهر]: ۲ ساعت و ۱۵ دقیقه»
- یک `Timer.periodic` هر ۳۰ ثانیه به‌روز شود.
- اگر کمتر از ۱۵ دقیقه مانده: برجسته‌تر (بزرگ‌تر شدن تدریجی).
- اگر وقت نماز رسیده: «🕌 الآن وقت اذان [مغرب] است» (رنگ تأکید، نه قرمز).

**ردیف پایین: اطلاعات زمینه**
- 📍 نام شهر (از `iran_cities`، قابل لمس برای تغییر)
- روش محاسبه (دانشگاه تهران / MWL / ... — قابل تنظیم در ⚙️)
- 🗓 **سه تاریخ:** شمسی (امروز) · قمری (۴ محرم ۱۴۴۷) · میلادی (۲۳ ژوئن ۲۰۲۶)

### انتخاب شهر
- شیت جست‌وجوی شهرها از `iran_cities` (۴۰۰+ شهر).
- جست‌وجو بر اساس نام شهر یا استان.
- پس از انتخاب → `app_settings['prayer_city_id']` به‌روزرسانی → `PrayerTimeProvider.cachePrayerTimes` → بازسازی UI.

## 🚫 کارت وضعیت (شرطی: زن در قاعدگی)

> شرط نمایش: `userGender == 'FEMALE'` و `cycle_logs` نشان دهد امروز در دوره‌ی قاعدگی است.

- یک کارت با بک‌گراند خنثی (خاکستری-بنفش ملایم) و متن: «امروز نماز و روزه به دلیل عادت ماهانه واجب نیست — خداوند این تخفیف را برای تو قرار داده است. 💜»
- **لحن:** محترمانه، مهربان، بدون شرم یا سرزنش.
- نمازهای واجب در بخش پایین **به‌صورت خودکار غیرفعال** (امروز انتظار نمی‌رود) ولی یادآورها **فردا** دوباره فعال می‌شوند.
- اگر کاربر باردار است (از `pregnancy_tracker`): «روزه‌داری در بارداری واجب نیست — سلامت تو و فرزندت اولویت دارد.»

## 📿 بخش ۱ — نمازهای واجب (Obligatory Prayers)

> داده: `app_settings` برای تیک‌های فعال‌سازی یادآوری · `prayer_times_cache` برای ساعات · `worship_practices` جدید برای ثبت انجام

پنج نماز واجب در یک لیست عمودی:

**هر ردیف:**
```
[✅ تیک فعال‌سازی]  [نام نماز]  [ساعت امروز]  ⏰ [X دقیقه قبل]
[⬜ انجام شد]                                          ← چک‌باکس امروز
```

- **تیک فعال‌سازی:** یادآوری این نماز را روشن/خاموش می‌کند. پیش‌فرض: همه روشن.
- **ساعت:** از `prayer_times_cache` امروز خوانده می‌شود.
- **یادآوری:** چند دقیقه قبل از اذان (قابل تنظیم per-namaz: صبح ۱۰دق، ظهر ۱۵دق، مغرب ۵دق...).
- **چک‌باکس انجام:** کاربر می‌تواند تیک بزند که امروز این نماز را خوانده. (اختیاری، نه اجباری).
  - ذخیره در `worship_practices (practiceType='PRAYER', subType='FAJR', date=today)`.
  - فردا ریست می‌شود.

**نوار وضعیت روزانه:**
`«امروز: ✅ ✅ ✅ ⬜ ⬜ — ۳ از ۵ نماز»`

> **بدون سرزنش:** اگر ۲ نماز خوانده نشده، متن: «۲ نماز دیگر در انتظار توست 🙏» (نه «۲ تا قضا شدی!»)

### اتصال هوشمند به بدهی‌ها
اگر نماز خوانده نشد و روز تمام شد → **خودکار** یک رکورد در `worship_debts` اضافه نشود. این یک تصمیم آگاهانه است — کاربر **خودش** باید بدهی را تأیید کند (اختیاری). ولی یک **پیشنهاد ملایم** در انتهای روز: «امروز نماز عصر و عشا رو نرسیدی — می‌خوای به بدهی‌ها اضافه کنم؟» (فقط در صورت تأیید کاربر).

|-------|-------------|------|

| نافله صبح | قبل از فجر | نماز |
| نافله ظهر | قبل از ظهر | نماز |
| نافله عصر | قبل از عصر | نماز |
| نافله مغرب | بعد از مغرب | نماز |
| نافله عشا | بعد از عشا | نماز |
| نماز اول ماه | ۱۰:۰۰ صبح | مناسبتی |
| زیارت عاشورا | ۶:۰۰ صبح | زیارت |
| دعای عهد | ۶:۳۰ صبح | دعا |

| دعای ندبه | جمعه صبح | دعا |

- هر ردیف: تیک فعال‌سازی + نام + زمان + (در صورت مناسبتی: «امروز پنجشنبه است»).
- کاربر می‌تواند **افزودن مستحب سفارشی** کند: نام + زمان + تکرار.
- ذخیره در `worship_practices (practiceType='MUSTAHAB')`.

## 📖 بخش ۳ — قرآن و ذکر (Quran & Dhikr)

> داده: `worship_practices` با `practiceType='QURAN'` یا `practiceType='DHIKR'`

### هدف روزانه قرآن
- تنظیم هدف: [X] صفحه در روز / [X] آیه در روز / [X] دقیقه در روز.
- **نوار پیشرفت:** `████████░░ ۸ از ۱۰ صفحه` با دکمه‌های ➕ و ➖ (هر +۱ یعنی یک صفحه خواندم).
- روند هفتگی: نمودار میله‌ای ساده.
- اگر کاربر به هدف رسید: «🎉 امروز هدفت کامل شد — خدا قبول کنه.»

### ذکرهای روزانه (شمارشگر)
لیستی از اذکار با شمارنده:

```
تسبیحات حضرت زهرا (س):
  الله اکبر  ۳۴  [➕]
  الحمدلله   ۳۳  [➕]
  سبحان الله ۳۳  [➕]
  ─────────────────
  ████████░░ ۱۲ از ۱۰۰  [🔄 ریست]

صلوات: ██████░░░░ ۴۵ از ۱۰۰  [➕][🔄]
استغفار: ███░░░░░░░ ۳۰ از ۷۰  [➕][🔄]
```

- هر ذکر: نام + هدف روزانه + شمارنده + دکمه‌ی ➕.
- دکمه‌ی شمارش بزرگ (قابل لمس آسان — برای استفاده حین ذکر گفتن).
- ریست خودکار هر روز.
- **افزودن ذکر سفارشی:** نام + هدف روزانه.

## 📋 بخش ۴ — بدهی‌های عبادی (Worship Debts)

> داده: `worship_debts` (id, debtType, title, totalCount, remainingCount, dailyTarget, autoCreated, isArchived)

### انواع پیش‌فرض بدهی
| نوع | عنوان | رفتار |
|-----|-------|-------|
| `PRAYER` | قضای نماز | کاربر تعداد کل + انجام‌شده را وارد می‌کند |
| `FAST` | قضای روزه | مشابه بالا |
| `KAFFAREH` | کفاره | عدم توانایی روزه → کفاره‌ی مالی |

### کارت هر بدهی
```
┌─ نماز قضا ──────────────────────────────────────┐
│ ████████░░ ۱۲۸ از ۲۰۰ (۶۴٪)                      │
│ هدف روزانه: [۳] نماز                             │
│ «اگه هر روز ۳ تا بخونی، ۲۴ روز دیگه تموم میشه»   │ ← تشویقی، محاسبه‌ی پویا
│ امروز: ⬜ ⬜ ⬜                                   │ ← چک‌باکس‌های امروز
└──────────────────────────────────────────────────┘
```

- هدف روزانه قابل تنظیم (پیش‌فرض: ۱).
- هر چک‌باکس که تیک بخورد → `remainingCount` یک واحد کم می‌شود.
- **متن تشویقی پویا:** «اگه هر روز [N] تا بخونی، [X] روز دیگه تموم میشه» یا «آفرین! تا حالا ۶۴٪ راه رو اومدی».
- **ثبت بدهی جدید:** title + debtType + totalCount + dailyTarget.
- **آرشیو:** بدهی‌های تمام‌شده به آرشیو بروند (غرور سالم — «تو تونستی تمومش کنی»).

> **قاعده‌ی طلایی بدهی‌ها:** هرگز حس گناه یا اضطراب ایجاد نکن. بدهی یک «فرصت جبران» است، نه «بار تحقیر». نمایش `dailyTarget` کم (۱–۳) برای تشویق به حرکت تدریجی.

## 📅 بخش ۵ — فصول عبادی (Worship Seasons)

> داده: `worship_seasons` · منطق موجود در `WorshipSeasonsSheet` استفاده شود، با ارتقا.

### کارت‌های فصل
هر فصل یک کارت با:
- **عنوان** (ماه رمضان / دهه محرم / اعتکاف / ...)
- **بازه‌ی تاریخ** (۱۵ اسفند - ۱۴ فروردین)
- **تقویم مبنا** (هجری شمسی / هجری قمری / میلادی)
- **وزن اولویت** (`priority_weight`: ۱.۰ عادی، ۲.۰ بالا، ۳.۰ حداکثر — روی اولویت‌بندی روتین‌ها در RIE اثر دارد)
- **فعال/غیرفعال** (toggle)

### فصل‌های پیش‌فرض (قابل ویرایش/حذف):
- ماه رمضان (هجری قمری: ۱ رمضان - ۳۰ رمضان)
- دهه محرم (هجری قمری: ۱ محرم - ۱۰ محرم)
- دهه ذی‌حجه (هجری قمری: ۱ ذی‌حجه - ۱۰ ذی‌حجه)
- ایام البیض (هر ماه قمری: ۱۳، ۱۴، ۱۵)
- شب‌های قدر (۱۹، ۲۱، ۲۳ رمضان)

### شیت افزودن/ویرایش فصل (از `WorshipSeasonsSheet` موجود با بهبود):
- عنوان · نوع فصل (`fasting`, `prayer`, `spiritual`, `custom`) · تاریخ شروع/پایان · تقویم مبنا (شمسی/قمری/میلادی) · وزن اولویت (اسلایدر ۱.۰–۳.۰) · فعال/غیرفعال.

### تأثیر روی RIE
فصل‌های فعال روی `priority_weight` روتین‌های عبادی در `resolveDailyBehavior` اثر می‌گذارند. این منطق از قبل در `context_engine.dart` و `ritmo_intelligence_engine.dart` وجود دارد.

## 🗄️ جدول جدید: `worship_practices`

```sql
CREATE TABLE worship_practices (
    id TEXT PRIMARY KEY,
    practiceType TEXT NOT NULL,       -- 'PRAYER', 'MUSTAHAB', 'QURAN', 'DHIKR'
    subType TEXT,                     -- 'FAJR', 'DHUHR', 'ASR', 'MAGHRIB', 'ISHA' (برای نماز واجب)
                                      -- 'NIGHT_PRAYER', 'NAFILAH', 'ZIARAT', 'DUA' (برای مستحب)
                                      -- 'PAGE', 'AYAH', 'MINUTE' (برای قرآن)
                                      -- 'TASBIH', 'SALAWAT', 'ESTEGHFAR', 'CUSTOM' (برای ذکر)
    title TEXT NOT NULL,              -- نام نمایشی
    dailyTarget INTEGER DEFAULT 1,    -- هدف روزانه
    dailyDone INTEGER DEFAULT 0,      -- انجام‌شده امروز
    totalTarget INTEGER,              -- هدف کلی (برای قرآن: مثلاً ۶۰۴ صفحه)
    totalDone INTEGER DEFAULT 0,      -- انجام‌شده کل
    reminderEnabled INTEGER DEFAULT 0, -- یادآوری فعال؟
    reminderTime TEXT,                -- زمان یادآوری (مثلاً «۰۵:۰۰»)
    reminderOffsetMinutes INTEGER,    -- چند دقیقه قبل از وقت نماز
    sortOrder INTEGER DEFAULT 0,      -- ترتیب نمایش
    isActive INTEGER DEFAULT 1,       -- فعال بودن در UI
    notes TEXT,                       -- یادداشت
    createdAt INTEGER NOT NULL,
    updatedAt INTEGER NOT NULL
);
```

## ✅ تصمیم‌های قطعی (قفل‌شده)

1. **سه تاریخ:** شمسی، قمری و میلادی هر سه در کارت Hero نمایش داده شوند. (هجری قمری با کتابخانه‌ی `hijri` یا محاسبه‌ی محلی.)
2. **یادآوری نماز، نه اذان:** بدون صدای اذان. نوتیفیکیشن متنی ساده. **قابلیت تعویق (Snooze):** کاربر بعد از یادآوری می‌تواند «خواندم» یا «یادآوری مجدد» (۱۵ / ۳۰ / ۶۰ دقیقه بعد) را انتخاب کند. اگر تعویق از وقت نماز بعدی گذشت، هشدار ملایم.
3. **بدهی خودکار = پیشنهاد + تأیید:** سیستم پیشنهاد می‌دهد، کاربر تأیید می‌کند — هرگز بدون تأیید.
4. **جهت قبله:** حذف کامل. زیاده‌روی است.
5. **یادآوری‌ها همگی اختیاری:** کاربر هر نماز/مستحب/ذکر را جداگانه فعال/غیرفعال می‌کند.

> این تصمیم‌ها مبنای `AGENT_PROMPT_WORSHIP.md` هستند.
